考研倒计时隐私政策

最后更新：2026年11月1日
版本：v1.3.0 · 邮箱：lovelili2000000@163.com

我们承诺保护您的隐私。您的学习数据（倒计时、学科、学习计划、番茄钟记录、院校信息）全部存储在您的设备本地，不会上传到我们或任何第三方的服务器。

在您明确同意后，应用会使用第三方统计分析服务（友盟+）收集匿名的功能使用统计，用于了解哪些功能真正被使用。您可以不同意，也可以随时在「设置 → 数据分析」中关闭，关闭后立即停止上报。我们不会收集您输入的任何内容，也不会将数据用于广告投放或跨应用追踪。

1. 信息收集

【本地存储的数据（不会上传）】您在应用内主动输入的学习数据，仅保存在您的设备上：

  • 考研日期与倒计时目标设置
  • 报考院校与专业信息
  • 学科信息与学习计划进度
  • 番茄钟专注会话记录（专注时长、学科关联、开始时间）
  • 番茄钟设置（专注/休息时长、自动开始、提醒方式）
  • 通知提醒设置（开关、提醒时间）
  • 应用偏好设置（主题颜色、深色模式、屏幕常亮）

【统计分析信息（仅在您同意后收集）】

  • 功能使用行为：如新建倒计时、开始番茄钟、勾选学习计划等动作的发生次数与时间
  • 应用偏好：主题颜色、深色模式
  • 运行环境：应用版本、系统版本、设备型号
  • 设备统计标识：由友盟 SDK 采集，仅用于区分不同设备、做去重统计

郑重声明：我们不会收集您输入的任何内容——倒计时标题、学科名称、院校名称、专业名称、备注均不会上传。我们也不会收集您的姓名、邮箱、电话、位置、通讯录、相册，不会读取 IDFA 用于广告追踪。

2. 数据使用

【本地数据】仅用于：

  • 显示考研倒计时与学习进度
  • 管理学科信息与学习计划
  • 运行番茄钟专注计时器并记录学习时长
  • 计算并展示学习统计数据（今日/本周专注、学科分布、近7天趋势）
  • 发送本地通知提醒（专注结束、休息结束）
  • 在主应用与桌面小组件之间共享数据显示
  • 提供个性化的应用界面（主题颜色、深色模式）

【统计分析信息】仅用于：

  • 统计各功能的使用频次与留存情况，用于决定后续开发优先级
  • 了解应用的整体使用规模与设备分布

统计分析信息不用于广告投放，不用于跨应用追踪，不用于识别您的个人身份。

3. 数据存储

【本地数据】使用 iOS 系统提供的本地安全存储机制进行保护：

  • 倒计时与学科数据：UserDefaults (App Groups)，共享范围：主应用 + 小组件
  • 番茄钟会话与设置：UserDefaults (App Groups)，共享范围：主应用 + 小组件
  • 通知设置与授权状态：UserDefaults (结构化存储)，共享范围：仅主应用
  • 主题与偏好：UserDefaults (App Groups)，共享范围：主应用 + 小组件

数据架构说明：应用采用 StorageManager 统一存储架构，所有数据访问通过单一入口管理，并使用 MigrationManager 数据迁移机制保证应用版本升级时已安装用户数据无丢失。

App Groups 共享：应用使用 group.com.kaoyan900.shared 应用组权限，仅在主应用与同开发者的桌面小组件之间共享数据，不会与任何其他应用或第三方共享。

【统计分析信息】由友盟在其服务器上按《友盟隐私政策》保存与处理。我们只能查看聚合后的统计报表（如“本周有 X 人使用了番茄钟”），无法从中定位到具体某位用户。

4. 权限使用

应用可能请求以下系统权限：

  • 通知权限 (Notifications)：用于发送倒计时提醒、番茄钟专注/休息结束提醒（可选）
  • 应用组权限 (App Groups)：用于主应用与桌面小组件之间共享倒计时与主题数据（可选）

权限管理：所有权限均为可选，您可随时在 iOS 系统的「设置 → 考研倒计时」中开启或关闭各项权限。关闭通知权限不影响应用其他功能的正常使用。

不申请的权限：应用不申请相机、麦克风、位置、通讯录、相片库、日历、健康、蓝牙、Face ID、本地网络等任何敏感权限，也不请求「允许 App 请求跟踪」（ATT）权限——因为本应用不进行跨应用追踪。

6. 儿童隐私

本应用面向考研学生群体，年龄分级为 4+（适合所有年龄）。应用不会故意收集任何儿童的个人信息，也不会向儿童推送任何商业内容或广告。

如果您是家长或监护人，发现您的孩子向我们提供了任何个人信息，请通过邮箱 lovelili2000000@163.com 联系我们，我们将及时删除相关信息。

7. 数据删除与授权撤回

您对自己的数据拥有完全控制权：

  • 撤回统计授权：在应用内「设置 → 数据分析」关闭开关，关闭后友盟 SDK 立即停止采集与上报
  • 删除本地数据：卸载应用，或在 iOS 系统的「设置 → 通用 → iPhone 存储空间 → 考研倒计时」中删除应用
  • 删除已上报的统计数据：应用内无法直接操作友盟服务器上的历史统计数据，请通过下方邮箱联系我们协助处理

删除即彻底：本地数据全部存储在您的设备上，卸载应用后将被永久删除且无法恢复，我们的服务器不会保留您的任何本地学习数据。

8. 政策更新

我们可能会不时更新本隐私政策。

当发生重大变更——尤其是涉及第三方 SDK、收集的信息类型或使用目的的变化时，我们会更新本页面的「最后更新」日期，并在应用下次启动时重新征求您的同意。我们不会以“继续使用即视为同意”的方式替代您的选择。

建议您定期查阅本页面以了解最新的隐私政策。
